🛠️ HERRAMIENTAS

20 programas y herramientas que deberías conocer

Programas esenciales para estudiar, programar, organizar archivos, crear contenido y trabajar con tecnología.

⏱️ 14–16 min de lectura🟢 Principiantes📅 Agosto 2026
⌨️🌿🐙🐍🟩🐧

Antes de empezar

No necesitas instalar decenas de programas. Conocer para qué sirve cada herramienta te ayuda a elegir mejor y a construir un entorno de trabajo simple.

💡 Consejo ByteNova

No intentes usar o aprender todo a la vez. Elige una opción, pruébala y decide si realmente mejora tu forma de trabajar o aprender.

20 opciones que vale la pena conocer

⌨️Código

Visual Studio Code

Editor de código extensible para programación y desarrollo web.

Ver explicación

Aprende primero lo básico: abrir carpetas, buscar archivos, terminal integrada y extensiones realmente necesarias.

🌿Versionado

Git

Registra cambios de un proyecto y permite trabajar con versiones.

Ver explicación

Dominar add, commit, status, log y ramas básicas te da mucho control sobre tus proyectos.

🐙Versionado

GitHub Desktop

Interfaz gráfica para trabajar con repositorios GitHub.

Ver explicación

Puede ayudarte al inicio si todavía no te sientes cómodo con todos los comandos de Git.

🐍Programación

Python

Lenguaje y entorno para ejecutar proyectos Python.

Ver explicación

Instalarlo correctamente y comprender cómo ejecutar archivos es un buen primer paso para aprender Python.

🟩JavaScript

Node.js

Permite ejecutar JavaScript fuera del navegador.

Ver explicación

Es habitual en herramientas modernas de desarrollo y proyectos backend.

🐧Sistemas

WSL / Linux

Entorno Linux útil para desarrollo y terminal.

Ver explicación

Te acerca a herramientas usadas en servidores y entornos profesionales.

📦Archivos

7-Zip

Comprime y descomprime múltiples formatos.

Ver explicación

Una herramienta sencilla para manejar paquetes, respaldos y archivos comprimidos.

🦊Navegador

Firefox

Navegador con herramientas de desarrollo integradas.

Ver explicación

Comparar tu web en más de un navegador ayuda a encontrar diferencias y problemas de compatibilidad.

🌐Desarrollo

Chrome DevTools

Herramientas para inspeccionar HTML, CSS, red y rendimiento.

Ver explicación

Aprender a usar Inspector, Console y Network acelera mucho la resolución de errores.

🧪APIs

Postman

Permite probar solicitudes y respuestas de APIs.

Ver explicación

Útil para comprender HTTP, endpoints, encabezados y datos JSON.

🐳Entornos

Docker Desktop

Ayuda a ejecutar aplicaciones en contenedores.

Ver explicación

No es necesario para empezar, pero conocer el concepto te prepara para proyectos más avanzados.

🎨Diseño

Figma

Herramienta para diseñar interfaces y prototipos.

Ver explicación

Puede ayudarte a planificar visualmente una web antes de escribir código.

🖼️Imagen

GIMP

Editor de imágenes gratuito y de código abierto.

Ver explicación

Sirve para retoque, composición y preparación de recursos gráficos.

🎬Contenido

OBS Studio

Graba pantalla y transmite contenido.

Ver explicación

Muy útil para tutoriales, demostraciones o documentación visual.

📝Notas

Obsidian

Organiza notas en archivos Markdown.

Ver explicación

Puede servir para construir una base personal de conocimiento técnico.

🔑Seguridad

Bitwarden

Gestor de contraseñas.

Ver explicación

Un gestor ayuda a usar contraseñas únicas sin tener que memorizarlas todas.

🔒Seguridad

VeraCrypt

Herramienta para cifrar volúmenes de almacenamiento.

Ver explicación

Útil para aprender conceptos de cifrado y proteger información sensible.

📊Ofimática

LibreOffice

Suite para documentos, hojas de cálculo y presentaciones.

Ver explicación

Alternativa gratuita para tareas de productividad general.

🔍Archivos

Everything

Búsqueda rápida de archivos en Windows.

Ver explicación

Puede ahorrar tiempo cuando trabajas con muchos proyectos y carpetas.

🧹Mantenimiento

BleachBit

Ayuda a limpiar archivos temporales y liberar espacio.

Ver explicación

Úsalo con criterio y revisa siempre qué elementos vas a eliminar.

Cómo aprovechar esta guía

Si vas a programar

Empieza con VS Code, Git, un navegador y el lenguaje que estés aprendiendo.

Si vas a diseñar

Figma y un editor de imágenes cubren gran parte de lo básico.

Si quieres seguridad

Usa un gestor de contraseñas y aprende a respaldar tus archivos.

No instales por instalar

Cada programa debería resolver una necesidad concreta.
