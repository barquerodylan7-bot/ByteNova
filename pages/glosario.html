📖 Glosario ByteNova

Conceptos tecnológicos explicados de forma simple

Aprende palabras importantes de programación, Internet, inteligencia artificial, ciberseguridad y tecnología digital sin complicarte.

Cómo usar este glosario

Este glosario funciona como un mapa de ByteNova. Busca el concepto que necesitas, lee una definición breve y, cuando exista una guía completa, usa “Aprende más →” para profundizar con ejemplos y contexto.

Ruta rápida para principiantes

  1. Empieza por Internet y redes: IP, DNS, URL, HTTP y servidor.
  2. Continúa con desarrollo web: HTML, CSS, JavaScript, frontend, backend y API.
  3. Avanza a programación y datos: algoritmo, variable, función, base de datos, SQL y JSON.
  4. Explora IA y ciberseguridad cuando ya tengas claros los fundamentos.

Diccionario tecnológico por categorías

Consulta definiciones rápidas y conecta cada concepto con los artículos de ByteNova para seguir aprendiendo.

🌐 Internet y redes

Conceptos para entender cómo se conectan los dispositivos y cómo llega una página hasta tu navegador.

Internet

Red mundial de redes conectadas que permite que dispositivos y servicios intercambien información mediante protocolos comunes.

Aprende más →

Dirección IP

Identificador numérico que permite localizar y comunicar dispositivos dentro de una red basada en el protocolo IP.

Aprende más →

DNS

Sistema que traduce nombres de dominio fáciles de recordar, como bytenova.app, a direcciones IP que las redes pueden utilizar.

Aprende más →

URL

Dirección de un recurso en la Web. Puede señalar una página, una imagen, un documento o una ruta específica dentro de un sitio.

Aprende más →

HTTP y HTTPS

Protocolos utilizados para intercambiar recursos entre navegador y servidor. HTTPS añade cifrado para proteger la comunicación.

Aprende más →

Servidor

Sistema que recibe solicitudes y entrega recursos o servicios a otros dispositivos llamados clientes.

Aprende más →

TCP/IP

Conjunto de protocolos fundamentales para la comunicación en Internet. IP se ocupa del direccionamiento y TCP ayuda a entregar datos de forma ordenada y confiable.

Aprende más →

Red informática

Conjunto de dispositivos conectados para intercambiar información y compartir recursos mediante medios cableados o inalámbricos.

Aprende más →

Navegador web

Programa que solicita recursos a servidores e interpreta HTML, CSS y JavaScript para mostrar páginas web.

Aprende más →

Dominio y hosting

El dominio es el nombre utilizado para llegar a un sitio; el hosting es la infraestructura donde se alojan sus archivos o servicios.

Aprende más →

Router

Dispositivo que dirige el tráfico entre redes y permite que varios equipos compartan una conexión.

LAN

Red de área local que conecta dispositivos dentro de un espacio limitado, como una casa, oficina o centro educativo.

Wi‑Fi

Tecnología de red inalámbrica que permite conectar dispositivos a una red local mediante ondas de radio.

Ancho de banda

Cantidad de datos que una conexión puede transportar durante un periodo determinado.

Latencia

Tiempo que tarda un dato en viajar desde su origen hasta su destino y obtener una respuesta.

🧱 Desarrollo web

Términos esenciales para comprender cómo se construyen, presentan y conectan los sitios y aplicaciones web.

HTML

Lenguaje de marcado que define la estructura y el significado del contenido de una página mediante elementos como títulos, párrafos, enlaces, imágenes y formularios.

Aprende más →

CSS

Lenguaje de estilos que controla presentación, colores, tipografía, espacios, distribución, animaciones y adaptación a diferentes pantallas.

Aprende más →

JavaScript

Lenguaje de programación que permite agregar lógica e interacción a páginas web y también puede utilizarse fuera del navegador.

Aprende más →

Frontend

Parte de una aplicación con la que interactúa directamente el usuario, normalmente construida con HTML, CSS, JavaScript y herramientas relacionadas.

Aprende más →

Backend

Parte que procesa lógica, autenticación, datos y comunicación con servicios o bases de datos antes de responder al frontend.

Aprende más →

API

Interfaz que define cómo dos programas pueden solicitar funciones o intercambiar información sin conocer todos los detalles internos del otro sistema.

Aprende más →

Diseño responsive

Enfoque que adapta la interfaz a diferentes tamaños de pantalla para mantener legibilidad y facilidad de uso en móviles, tablets y computadoras.

Aprende más →

Accesibilidad web

Prácticas que buscan que sitios y aplicaciones puedan ser utilizados por la mayor cantidad de personas posible, incluidas personas con distintas discapacidades.

Aprende más →

SEO

Conjunto de prácticas para ayudar a buscadores a comprender un sitio y ofrecer a las personas contenido útil, accesible y bien organizado.

Aprende más →

Cookies

Pequeños datos que un sitio puede guardar mediante el navegador para recordar sesiones, preferencias u otra información entre solicitudes.

Aprende más →

DOM

Representación estructurada de una página que permite a JavaScript consultar y modificar elementos HTML.

Framework

Conjunto de herramientas y convenciones que proporciona una estructura para desarrollar aplicaciones.

Biblioteca de software

Colección de código reutilizable que ofrece funciones para resolver tareas específicas.

Caché

Almacenamiento temporal de recursos para acelerar cargas posteriores y reducir solicitudes innecesarias.

Cookie

Pequeño dato que un sitio puede guardar en el navegador para recordar información o gestionar determinadas funciones.

💻 Programación y datos

Conceptos que aparecen constantemente al aprender lógica, escribir programas y trabajar con información.

Programación

Proceso de diseñar instrucciones y escribir código para que una computadora realice tareas o resuelva problemas.

Aprende más →

Algoritmo

Secuencia finita y ordenada de pasos para resolver un problema o alcanzar un resultado. Puede existir antes de escribir código.

Aprende más →

Variable

Nombre asociado a un valor que un programa puede utilizar y, según el lenguaje y el contexto, modificar durante su ejecución.

Aprende más →

Función

Bloque reutilizable de instrucciones que realiza una tarea y puede recibir datos de entrada y devolver un resultado.

Aprende más →

Condicional

Estructura que permite ejecutar acciones diferentes dependiendo de si una condición se cumple o no.

Aprende más →

Bucle

Estructura que repite instrucciones mientras se cumpla una condición o durante una cantidad determinada de iteraciones.

Aprende más →

Array o lista

Estructura que agrupa varios valores para poder almacenarlos, recorrerlos y procesarlos de manera organizada.

Aprende más →

Programación orientada a objetos

Paradigma que organiza programas alrededor de objetos, clases, propiedades y comportamientos relacionados.

Aprende más →

Base de datos

Colección estructurada de información diseñada para almacenar, consultar, relacionar y modificar datos de forma organizada.

Aprende más →

SQL

Lenguaje utilizado para consultar y manipular información en muchas bases de datos relacionales.

Aprende más →

JSON

Formato de texto para representar datos estructurados mediante objetos, arrays y valores. Es muy común en APIs y aplicaciones web.

Aprende más →

Git

Sistema de control de versiones que registra cambios en archivos y permite trabajar con historial, ramas y colaboración.

Aprende más →

Terminal

Interfaz de texto desde la que se ejecutan comandos, programas y herramientas de desarrollo mediante una shell.

Aprende más →

Compilador e intérprete

Mecanismos que transforman o ejecutan código fuente. Los lenguajes modernos pueden combinar compilación, bytecode, máquinas virtuales e interpretación.

Aprende más →

GitHub

Plataforma para alojar repositorios Git y colaborar en proyectos de software.

Repositorio

Espacio donde se almacenan los archivos de un proyecto junto con su historial de cambios.

Commit

Registro de un conjunto de cambios guardados en el historial de un repositorio Git.

Linux

Familia de sistemas operativos de código abierto ampliamente utilizada en servidores, desarrollo y tecnología.

🤖 Inteligencia artificial

Ideas clave para entender cómo los sistemas aprenden patrones, procesan lenguaje y generan contenido.

Inteligencia artificial

Campo que desarrolla sistemas capaces de realizar tareas asociadas con percepción, predicción, lenguaje, decisión o generación de contenido.

Aprende más →

Machine learning

Área de la IA donde los sistemas aprenden patrones a partir de datos para realizar predicciones o tomar decisiones sin programar cada regla manualmente.

Aprende más →

Deep learning

Subcampo del aprendizaje automático que utiliza redes neuronales con múltiples capas para aprender representaciones complejas.

Aprende más →

Red neuronal

Modelo computacional formado por capas de unidades conectadas que transforman información mediante parámetros aprendidos.

Aprende más →

LLM

Modelo de lenguaje de gran escala entrenado para trabajar con secuencias de texto y otros datos, capaz de generar respuestas a partir del contexto recibido.

Aprende más →

NLP

Procesamiento del lenguaje natural: área que estudia cómo los sistemas informáticos analizan, representan y generan lenguaje humano.

Aprende más →

Embedding

Representación numérica de información que permite capturar relaciones y similitudes útiles para modelos de aprendizaje automático.

Aprende más →

IA generativa

Sistemas capaces de producir contenido nuevo, como texto, imágenes, audio o código, a partir de patrones aprendidos y una entrada del usuario.

Aprende más →

Prompt engineering

Práctica de diseñar instrucciones y contexto de forma clara para obtener resultados más útiles y controlables de sistemas de IA generativa.

Aprende más →

Agente de IA

Sistema que combina un modelo con objetivos, contexto y herramientas para realizar pasos y ejecutar acciones dentro de límites definidos.

Aprende más →

Modelo de lenguaje

Sistema entrenado con grandes cantidades de texto para procesar y generar lenguaje a partir de patrones aprendidos.

Token

Unidad en la que un modelo divide una entrada antes de procesarla; puede representar una palabra, parte de ella o un símbolo.

Prompt

Entrada o instrucción proporcionada a un sistema de inteligencia artificial para orientar la respuesta.

Alucinación

Respuesta generada por un sistema de IA que puede parecer convincente pero contiene información incorrecta o inventada.

🛡️ Ciberseguridad

Conceptos para reconocer riesgos digitales y comprender las principales capas de protección.

Ciberseguridad

Conjunto de prácticas, procesos y tecnologías utilizadas para proteger sistemas, redes, cuentas y datos frente a accesos o acciones no autorizadas.

Aprende más →

Vulnerabilidad

Debilidad en software, hardware, configuración o procesos que puede aumentar el riesgo si una amenaza logra aprovecharla.

Aprende más →

Malware

Software creado con intenciones maliciosas, por ejemplo para dañar, espiar, robar información o alterar el funcionamiento de un sistema.

Aprende más →

Phishing

Engaño que intenta conseguir credenciales o información sensible haciéndose pasar por una entidad o persona confiable.

Aprende más →

Ransomware

Tipo de malware que bloquea o cifra información y busca presionar a la víctima para obtener un pago.

Aprende más →

Firewall

Control de seguridad que filtra tráfico de red según reglas para permitir o bloquear determinadas comunicaciones.

Aprende más →

Autenticación en dos pasos

Método que exige un segundo factor además de la contraseña para dificultar el acceso no autorizado a una cuenta.

Aprende más →

VPN

Tecnología que crea un túnel cifrado entre un dispositivo y un servidor VPN para proteger el tráfico durante ese trayecto.

Aprende más →

Ingeniería social

Técnicas de manipulación que buscan aprovechar la confianza, urgencia o comportamiento humano para obtener información o acceso.

Aprende más →

Contraseña segura

Credencial diseñada para ser difícil de adivinar o reutilizar. La longitud, unicidad y un gestor de contraseñas son factores importantes.

Aprende más →

Autenticación de dos factores (2FA)

Método que solicita una segunda forma de verificación además de la contraseña para acceder a una cuenta.

Cifrado

Proceso que transforma información para que solo pueda interpretarse con la clave o mecanismo adecuado.

Cómo aprovechar el glosario

📖

Úsalo como guía de estudio

Usa este glosario como apoyo mientras lees los artículos y guías de ByteNova. Si encuentras un concepto que no conoces, revisa primero su definición y después continúa con el artículo relacionado cuando quieras una explicación más completa, ejemplos y contexto.

🔗

Todo está conectado

Muchos conceptos tecnológicos están conectados entre sí. Por ejemplo, comprender qué son una dirección IP, DNS, un servidor y una URL facilita entender cómo funciona la Web; de la misma forma, distinguir malware, phishing, ransomware y autenticación en dos pasos ayuda a construir una base más clara de ciberseguridad.

💡
Consejo para estudiar

No intentes memorizar todas las definiciones. Úsalas como referencia y vuelve a consultarlas cuando aparezcan en un tema nuevo. Relacionar cada término con un ejemplo suele ser más útil que aprenderlo de memoria.
