📚 DICCIONARIO DE ERRORES

Errores comunes y cómo interpretarlos

Guía rápida para entender mensajes de error frecuentes antes de buscar una solución.

📚 ERRORES COMUNES

Entiende el mensaje antes de intentar arreglarlo

Un error es información. Aprende a leer qué capa está fallando: navegador, código, servidor, red o Git.

404 Not Found

404 Not Found

La ruta solicitada no existe en el servidor.

✅ Revisa la URL, enlaces internos y nombres de archivo.
403 Forbidden

403 Forbidden

El servidor entendió la solicitud pero no permite el acceso.

✅ Revisa permisos, autenticación y reglas del servidor.
500 Internal Server Error

500 Internal Server Error

Ocurrió un fallo inesperado en el servidor.

✅ Busca logs y prueba el flujo que genera el error.
CORS

CORS

El navegador bloquea una solicitud entre orígenes por políticas de seguridad.

✅ Configura correctamente los encabezados CORS en el servidor.
Cannot GET /ruta

Cannot GET /ruta

El servidor de desarrollo no encuentra esa ruta.

✅ En sitios estáticos locales usa rutas a archivos reales como .html.
ReferenceError

ReferenceError

JavaScript intenta usar una variable o identificador que no existe.

✅ Revisa nombre, alcance y orden de ejecución.
TypeError

TypeError

Una operación se intenta sobre un valor de tipo incompatible.

✅ Comprueba el valor real antes de llamar métodos o acceder propiedades.
SyntaxError

SyntaxError

El código no cumple la sintaxis esperada.

✅ Revisa paréntesis, llaves, comillas y estructura.
Module not found

Module not found

La herramienta no encuentra un módulo o archivo importado.

✅ Verifica instalación, ruta y nombre exacto.
git non-fast-forward

git non-fast-forward

Tu rama local y la remota no están en una línea de historial que permita avanzar directamente.

✅ Haz fetch y compara historiales antes de pull, rebase o force.
Merge conflict

Merge conflict

Git no puede decidir automáticamente qué versión conservar.

✅ Abre los archivos en conflicto, decide el contenido correcto y marca la resolución.
Permission denied

Permission denied

El sistema bloquea una operación por permisos insuficientes.

✅ Comprueba propietario, permisos y contexto antes de usar privilegios elevados.
