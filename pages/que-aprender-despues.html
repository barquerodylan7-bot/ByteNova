🧭 ORIENTACIÓN

¿Qué deberías aprender después?

Selecciona el punto en el que estás y sigue una secuencia sencilla para continuar avanzando.

🧭 ORIENTADOR RÁPIDO

Elige dónde estás ahora

No existe una sola ruta correcta. Usa estas recomendaciones como mapa, no como obligación.

🌐

Ya sé HTML y CSS

Si ya puedes estructurar y diseñar páginas, el siguiente salto es agregar lógica e interacción.

JavaScript → Git/GitHub → APIs → Proyecto frontend
🐍

Ya sé Python básico

Después de variables y ciclos, empieza a conectar datos y construir programas con propósito.

Funciones → archivos → APIs → SQL → proyecto
🟨

Ya sé JavaScript básico

Antes de saltar a un framework, asegúrate de dominar eventos, funciones y manipulación del DOM.

DOM → módulos → APIs → Git → framework
🛡️

Me interesa ciberseguridad

La seguridad se entiende mejor cuando conoces primero cómo funcionan sistemas y redes.

Redes → Linux → terminal → seguridad web → laboratorios seguros
🤖

Me interesa inteligencia artificial

No necesitas empezar entrenando modelos: primero aprende fundamentos y cómo usar herramientas con criterio.

Python → datos → ML básico → prompts → APIs de IA
🗄️

Quiero aprender bases de datos

Empieza por almacenar y consultar datos antes de pensar en arquitecturas complejas.

SQL → modelado → relaciones → consultas → integración con una app
📌 Consejo

Cuando puedas explicar un concepto y construir algo pequeño con él, probablemente ya estás listo para avanzar.

🎯 ANTES DE AVANZAR

¿Cómo saber si estás listo para el siguiente tema?

No necesitas memorizar todo. Intenta explicar lo aprendido con tus propias palabras y construir algo pequeño sin seguir cada paso de un tutorial.

Comprende

Identifica qué problema resuelve la tecnología y reconoce sus conceptos principales.

Practica

Haz ejercicios cortos hasta poder modificar ejemplos y predecir qué ocurrirá.

Construye

Crea un proyecto pequeño. Los errores que aparezcan te mostrarán qué conocimientos necesitas reforzar.

📌 No conviertas la ruta en una carrera

Si un paso todavía te cuesta, vuelve a practicarlo. Avanzar con fundamentos claros suele ser más útil que acumular tecnologías sin saber cuándo utilizarlas.
