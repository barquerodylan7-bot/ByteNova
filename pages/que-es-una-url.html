¿Qué es una URL? Partes, ejemplos y seguridad 🔗

Publicado por ByteNova · 17 de julio de 2026 · Actualizado el 3 de agosto de 2026

En este artículo aprenderás:

Qué es una URL, cómo se divide en protocolo, dominio, ruta, parámetros y fragmentos, en qué se diferencia de un enlace y cómo reconocer direcciones confiables antes de abrirlas.

Cada vez que visitas una página, descargas un archivo o compartes un enlace, utilizas una URL. Esta dirección le indica al navegador qué recurso debe buscar, dónde se encuentra y, en muchos casos, cómo debe solicitarlo.

Comprender una URL no solo ayuda a navegar mejor. También es útil para crear páginas web, reconocer enlaces sospechosos, organizar contenido y entender cómo funciona Internet.

¿Qué es una URL?

URL significa Uniform Resource Locator, o localizador uniforme de recursos. Es la dirección única que permite localizar un recurso disponible en una red, normalmente Internet.

Ese recurso puede ser una página HTML, una imagen, un video, un archivo PDF, una hoja de estilos, una API o una sección concreta dentro de una página.

Ejemplo básico
https://bytenova.app/pages/que-es-una-url.html

Esta dirección indica que el navegador debe usar HTTPS, conectarse al dominio bytenova.app y solicitar el archivo ubicado dentro de la carpeta pages.

Ejemplo real paso a paso

Cuando escribes una URL en el navegador, ocurre un proceso parecido a este:

  1. El navegador separa el protocolo, el dominio y la ruta.
  2. Consulta el sistema DNS para conocer la dirección IP del dominio.
  3. Establece una conexión con el servidor correspondiente.
  4. Solicita el recurso indicado en la ruta.
  5. El servidor responde y el navegador muestra el contenido.
Una URL funciona como una dirección completa

El dominio sería parecido al nombre de un edificio y la ruta sería la habitación específica dentro de ese edificio.

Partes principales de una URL

https://blog.ejemplo.com/articulos/redes.html?modo=lectura#resumen

1. Protocolo

https:// indica el método de comunicación. En páginas web se utilizan principalmente HTTP y HTTPS. HTTPS protege la información durante el intercambio entre el navegador y el servidor.

2. Subdominio

blog. es una sección opcional del dominio. Puede separar áreas como documentación, tienda, soporte o noticias.

3. Dominio

ejemplo.com identifica el sitio. Está compuesto por un nombre y una extensión, como .com, .org, .app o .net.

4. Ruta

/articulos/redes.html señala la ubicación del recurso dentro del sitio.

5. Parámetros

?modo=lectura envía información adicional. Los parámetros comienzan con ? y varios valores pueden separarse con &.

6. Fragmento

#resumen lleva al usuario a una sección específica del documento. El fragmento normalmente no se envía al servidor.

Diferencia entre URL, dominio y enlace

  • Dominio: identifica el sitio, por ejemplo bytenova.app.
  • URL: es la dirección completa de un recurso.
  • Enlace: es el elemento visible que permite abrir una URL.

Un botón con el texto “Leer el artículo” es un enlace. La dirección que ese botón abre es la URL.

URL absolutas y rutas relativas

URL absoluta

https://bytenova.app/pages/que-es-dns.html

Incluye protocolo, dominio y ruta. Funciona aunque se copie desde otra página o aplicación.

Ruta relativa

que-es-dns.html

Se interpreta desde la ubicación del documento actual. Es útil dentro de un mismo proyecto porque evita repetir el dominio completo.

Ejemplo en HTML
<a href="que-es-dns.html">Aprender sobre DNS</a>

Parámetros y fragmentos

Los parámetros suelen utilizarse para filtros, búsquedas, campañas, idiomas o estados de una aplicación:

https://ejemplo.com/buscar?tema=python&nivel=basico

Los fragmentos permiten enlazar directamente a una sección:

https://ejemplo.com/guia.html#preguntas

Una misma página puede abrirse con distintos parámetros, pero eso no siempre significa que exista contenido diferente. Por esa razón, los sitios deben administrar bien sus URL canónicas.

Cómo reconocer una URL segura

  • Comprueba que el dominio esté escrito correctamente.
  • Prefiere HTTPS, especialmente al introducir contraseñas o datos personales.
  • Desconfía de dominios que imitan marcas cambiando una letra.
  • No te fíes solo del texto visible del enlace; revisa la dirección real.
  • Evita abrir enlaces acortados de procedencia desconocida.
  • Ten cuidado con parámetros extraños o descargas inesperadas.
Ejemplo de suplantación

micuenta-banco-seguro.example puede contener palabras confiables, pero el dominio real sigue siendo example. Lo importante es identificar el dominio registrado, no solo leer el comienzo de la dirección.

¿Por qué las URL importan para el SEO?

Una URL clara ayuda a usuarios y buscadores a comprender el tema de la página. Una dirección descriptiva suele ser más fácil de recordar, compartir y mantener.

URL clara
/pages/que-es-una-url.html
URL poco descriptiva
/page?id=1847&x=92

Buenas prácticas: utilizar palabras comprensibles, mantener una estructura estable, evitar parámetros innecesarios, usar guiones y configurar redirecciones cuando una dirección cambie.

Errores frecuentes al trabajar con URL

  • Cambiar una URL sin crear una redirección.
  • Usar rutas relativas desde una carpeta incorrecta.
  • Confundir mayúsculas y minúsculas en servidores que las distinguen.
  • Copiar una dirección incompleta.
  • Incluir espacios sin codificar.
  • Crear varias URL para el mismo contenido sin una canónica.
  • Publicar direcciones demasiado largas o difíciles de entender.

Práctica rápida

Observa esta dirección:

https://docs.ejemplo.com/guias/html.html?tema=enlaces#ejercicio

Identifica: protocolo, subdominio, dominio, ruta, parámetro y fragmento. La respuesta es: https, docs, ejemplo.com, /guias/html.html, tema=enlaces y ejercicio.

Preguntas frecuentes

¿URL y dominio son lo mismo?

No. El dominio identifica el sitio; la URL puede incluir protocolo, dominio, ruta, parámetros y fragmentos.

¿Toda URL debe comenzar con HTTPS?

No. Existen otros protocolos, pero HTTPS es el estándar recomendado para la web porque cifra la comunicación.

¿Qué diferencia hay entre una URL y un enlace?

La URL es la dirección. El enlace es el texto, botón o imagen que permite abrirla.

¿Qué pasa si cambio la URL de una página?

La dirección anterior dejará de funcionar, salvo que se configure una redirección hacia la nueva ubicación.

¿Los parámetros forman parte de la URL?

Sí. Se agregan después del signo de interrogación y permiten enviar información adicional.

Resumen: lo que aprendiste

  • Una URL localiza un recurso concreto.
  • Puede incluir protocolo, subdominio, dominio, ruta, parámetros y fragmento.
  • Dominio, URL y enlace son conceptos relacionados, pero distintos.
  • Las direcciones claras favorecen la navegación, el mantenimiento y el SEO.
  • Revisar el dominio real ayuda a evitar enlaces fraudulentos.
